# Project instructions
Work only on this Pinterest project. Implementation belongs on develop; main is an initialization seed. Never deploy, merge, force-push or commit credentials. Keep downloader fail-closed without documented platform authorization and content-owner permission. The user superseded the API-only decision on 2026-11-27: retain official API mode and allow a separate, explicit opt-in anonymous public-page provider for permitted personal use. Public availability does not grant permission for automated access; document Pinterest restrictions. Parse only the requested Pin and require positive public signals. Never bypass login, CAPTCHA, bot blocks, private/restricted content or DRM. No undocumented API requests, cookies, session tricks, third-party resolvers or remote FFmpeg. Use dependency injection for fixtures, never a runtime bypass. Test each coherent change and make a conventional commit immediately after successful checks. Update PLAN.md with decisions and evidence. Use Node 24 and bounded streaming without persistent media.
